## 修复范围

| 问题 | 结果 |
|---|---|
| 抓取正文含登录上下文，通过匿名 API 回传 | 公开 Feed 不再查询/返回 cleaned_text；分类使用明确白名单投影，不返回证据 quote、input_hash、origin 和任意原始 payload。结构化题目若误含同类上下文也会屏蔽公开内容。原始档案保留，后台仍可查看证据并人工更正分类。 |
| 基础设施端口公开、默认密码 | 开发 Compose 绑定回环。独立生产 Compose 强制随机密钥，仅公开 80/443，数据库/Redis/API/Web 不映射宿主机端口；Langfuse 是可选配置且只绑定回环。后台路径与所有 API 别名均受 IP 限制与 Bearer 认证。 |
| 检索无匿名资源保护，非法参数 500 | 生产每 IP 普通请求 120/min、检索 12/min；Redis 不可用时拒绝请求。单 API 进程最多 1 个编码任务；超时/断连不提前释放计算名额。分页、质量分、偏移和公开 ID 增加边界校验。 |
| 缓存可挤占任务/预算状态 | 生产使用两个 Redis 实例：状态 AOF/noeviction，缓存 allkeys-lru。数据缓存 revision 留在状态实例，预算与队列不随缓存淘汰。 |
| 容器构建与运行未验证 | uv 在源码复制前只安装依赖，用已有虚拟环境安装 Playwright；运行不自动同步依赖，使用非 root 用户。Next.js 用 standalone 产物启动，运行阶段无需 TypeScript 自动安装。Dockerignore 排除所有环境/私有文件。 |
| 迁移、备份和恢复流程不足 | 顺序迁移、SHA-256、版本表、数据库锁、事务登记；提供每日备份 systemd timer、独立库恢复、校验、发布与回滚说明。备份/密钥文件自动保护 Unix 权限及 Windows NTFS ACL。 |
| 过期摘要、季度和管理操作混入公共页面 | 公开页仅浏览/面经/检索；435 份历史摘要保留后台并注明历史；季度动态生成。生成与导出位于管理后台，公开题目不显示勾选或“加入八股”。后台原题列表分页加载。 |
| 后端依赖新增安全发现 | 初始 pip-audit 报告 10 个包、15 条漏洞记录。升级到修复版本并给直接/传递依赖添加安全下限，禁止模型远程代码。固定版 torch 2.13、sentence-transformers 5.6 重新完成生产与 GPU 验证。 |
